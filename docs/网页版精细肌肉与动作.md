# 网页版精细肌肉与动作

## 当前可以试什么

`npm install && npm run build && npm run preview`，打开 `http://127.0.0.1:4173/`。默认直接显示精细肌肉表面；可旋转、缩放、播放或拖动进度条，切换静止、徒手深蹲、卧推、实力举。骨骼和肌肉肌腱路径可单独打开。动作中颜色按 OpenSim **整条肌肉肌腱路径**相对静止长度变化：红色变长、蓝色变短。颜色不是激活、力量或发力点。

如需自定义姿态，用已安装 OpenSim 4.6 与 SciPy 的 Python 运行 `.cache/opensim-venv/Scripts/python.exe scripts/live_pose_server.py --port 5173`，打开 `http://127.0.0.1:5173/`。在“自定义姿态”中可调七组关节滑块，也可拖动双手圆点，松开后由同一 OpenSim 模型对手部目标做逆运动学拟合，并重新计算全部体段和肌肉肌腱路径。当前左右联动、脚跟可固定，拖拽约需数秒；尚未实现脚部拖拽及连续实时运动仿真。只启动 Vite 静态预览时，预设动作仍可用，自定义姿态服务不可用。

静止和所有动作均使用 `cyclistFullBodyMuscle.osim` 的 80 个体段变换、520 条肌肉肌腱路径及长度。网页不再切换另一套动作模型。精细肌肉外形由 Z-Anatomy 的 68 块主要肌肉表面提供，配准并蒙皮到这套 OpenSim 骨段；它是同一场景的一层视觉几何，不提供第二套关节运动学或肌肉力学。网页加载约 10.5 MB 表面 GLB、0.39 MB 蒙皮权重及约 19.9 MB OpenSim 动作数据；手机浏览器的性能尚需实机验收。

## 来源、许可和几何精度

- [OpenSim 主模型](https://github.com/ross-wilkinson/opensim-model-fullBodyMuscleActuated)，固定提交 `3cfbe329a8ef9412494980419cb7177c41183a53`，MIT。`assets/opensim/cyclistFullBodyMuscle.osim` 是用于本地实时服务的同源副本。模型面向骑行，作者指出椎骨显示不准确，上身驱动有局限。
- [Pose2Sim 几何库](https://github.com/perfanalytics/pose2sim/tree/68304b47195dac80bc341cdfd9669140609358c4/Pose2Sim/OpenSim_Setup/Geometry)，BSD-3-Clause。只补主模型已引用的同名网格。83 个引用网格进入画面；37 个引用缺文件，12 节胸椎因源模型显示错位排除。许可见 `public/models/NOTICE-unified-opensim.txt`。
- [Z-Anatomy](https://github.com/Z-Anatomy/Models-of-human-anatomy) 解剖表面，CC BY-SA 4.0，包含 BodyParts3D 衍生内容。配准后的 `public/models/unified_muscle_surfaces.glb` 及权重作为衍生内容继续按 CC BY-SA 4.0 分发，署名见 `public/models/NOTICE-z-anatomy.txt`。这套表面没有原生 OpenSim 肌肉纤维模型。

`scripts/build_unified_muscle_surfaces.py` 以 15 对同名骨的中点拟合全局相似变换，并为上臂和前臂表面做局部骨位移修正。配准报告写入 `public/data/unified_muscle_skin.json`：骨中点 RMS 约 3.6 cm；髋和股骨约 1 cm，胫骨约 2.3 cm，未做局部修正前前臂约 5–6 cm。局部修正只是视觉定位，未经过专家逐块验证。肌肉表面的两端权重由相应 OpenSim 肌肉路径与附着骨段推导；小腿肌腹单独固定在胫骨上，避免把肌腹当作跟腱从膝盖拉到跟骨。形变仍是简单线性蒙皮，不等于真实组织形变；穿模、附着点和个体比例有待系统核验。

## 动作轨迹与边界

`scripts/export_unified_opensim.py` 输出 101 帧/动作，动作角度是明确写出的教学预设，**不是**从实测训练录像做的逆运动学。徒手深蹲的髋膝屈曲和双臂前摆同步，骨盆平移使双脚跟在起始位置着地；卧推取仰卧姿态、双脚跟着地，双肘伸展让双手沿竖直方向移动，网页展示凳和杠铃；实力举让双手从胸前移动到头顶上方。脚跟位置和手部关键轨迹有数值检查，**足底完整接触、杠铃接触、重心平衡和外力没有求解**。

原骑行模型的肩升举角上限约 2.01 rad，不足以达到过顶锁定。导出和实时服务都把同一 OpenSim 模型的肩关节数值范围临时延长至 3.1 rad；该范围的肌肉包绕与长度变化未经验证，尤其不能据此推断肩部力量。卧推的凳和杠铃仅是视觉参照，没有力学接触或重量。模型的姿态、体型和肌肉量尚未按个人参数调整。拖动手部后只做位置拟合；没有重新求解肌肉激活、动态力或关节反力。

## 复现和检查

在 `.cache/model-candidates/opensim-model-fullBodyMuscleActuated` 克隆主模型，在 `.cache/model-candidates/pose2sim` 克隆 Pose2Sim；安装 OpenSim 4.6 Python、NumPy、Trimesh 和 SciPy。执行：

```powershell
python scripts/export_unified_opensim_meshes.py
.cache/opensim-venv/Scripts/python.exe scripts/export_unified_opensim.py --samples 101
python scripts/build_unified_muscle_surfaces.py
npm run check:unified-data
npm run build
npm run check:unified-ui
.cache/opensim-venv/Scripts/python.exe scripts/live_pose_server.py --port 5173
```

发行的预计算数据已在仓库中；普通网页版运行不需要安装 OpenSim。当前验收包括 304 帧、520 条路径、68 块表面、深蹲/卧推脚跟接触和卧推/实力举手部位移，以及浏览器加载、动作切换和读取数值。旧版 v133 研究脚本与结果仍在仓库中，不代表当前首页。
