# 自由摆姿与肌肉路径：v133

## 这一版可以做什么

在三维工作台选择深蹲、卧推或实力举，先用时间轴找到一个预设姿势，再点「自由摆姿」。桌面鼠标或手机触摸可拖动左右手腕、左右脚踝的彩色圆点；肘、膝按两段骨骼长度约束重算。点空白处旋转视角。「恢复当前预设姿势」清除拖动；「结束自由摆姿」返回时间轴和播放。编辑姿势只在当前会话中保留，不写入个人训练记录。

默认视图显示来自 `RajagopalLaiUhlrich2023.osim` 的骨骼网格与 80 条双侧下肢肌肉路径。导出数据为每个路径点记录所属 OpenSim 骨段。每次姿势变化时，路径点随骨段刚性旋转、平移，并按用户身高／示意骨长缩放。蓝色代表整条路径相对当前预设姿势变长超过 2.5%，紫色代表变短超过 2.5%；悬停能看到名称和变化百分比。上肢与躯干的 23 条示意路径仍来自简化骨架，界面分别计数，避免与下肢 OpenSim 路径混为一谈。

44 个 OpenSim wrapping 面只在默认静止姿势显示。任意拖动或播放时没有重算绕行点，所以这版的动态长度是**骨段绑定的几何近似**，不是 OpenSim 对该姿势重新求得的肌肉肌腱长度。它也不表示肌纤维应变、肌电激活、肌肉收缩力、关节接触力或用户真实发力。由手脚末端求肘膝的逆运动学只有两段约束，尚未解决骨盆、肩胛、脊柱与手部自由度，不能作为临床或动作技术判定。

## 数据与实现

- 来源模型：OpenSim `opensim-models/Models/Rajagopal/RajagopalLaiUhlrich2023.osim`；本地导出器从 `.cache/model-candidates/opensim-models/` 读取该模型，缓存中的源文件不随 App 打包。导出器：`scripts/export_full_body_muscle_paths.py`；随包数据：`docs/data/full_body_muscle_paths.json`。导出时记录默认关节位置、每条路径的坐标及各点所属骨段。
- 渲染：`src/model.ts` 中的 `applyPoseOverrides` 保持大腿、小腿、上臂、前臂长度；`musclePathFrames` 将源骨段映射至教学骨架；`reshapeMuscleTube` 原位更新 80 条管网格，避免逐帧新建几何。
- 界面：`src/main.ts` 保留预设动作与自由摆姿的独立状态。编辑时暂停播放、锁住时间轴，并在页面内标明计算边界。

## 本期验证与下一步

`npm run build`、`npm run check:ui-dom` 已通过。浏览器验收实际拖动右踝，确认模型端点移动、股骨和胫骨长度误差小于 1 mm、至少一条下肢路径变化、重置后变化归零。桌面布局、对比度与悬停标签检查也已通过。Android 已有 Capacitor 工程；手机真机的拖动手感与帧率仍需实测。

下一阶段优先在 OpenSim 离线计算端针对用户编辑的姿势重新求 wrapping 路径，并补齐可信的双侧上肢、肩胛与躯干模型；随后用独立动作数据审查关节运动与路径，再考虑关节净力矩和肌肉力。只有受力估计经过模型收敛与独立实验验证，才开放「发力」着色。
