Android 原生容器现通过 Capacitor Filesystem 把 JSON 写入应用私有缓存，再通过 Share 插件交给系统分享菜单保存或传送；网页端继续使用 Web Share／下载。Android 清单关闭 Auto Backup，并为 Android 11 及更早版本和 Android 12 及更新版本分别配置云备份、设备转移排除规则，避免默认把身体数据纳入系统自动迁移。用户主动导出的文件由用户选择去处；清除应用数据前需要自行保存备份。规则依据 [Android Auto Backup 文档](https://developer.android.com/identity/data/autobackup)，分享路径依据 [Capacitor Share](https://capacitorjs.com/docs/apis/share) 与 [Filesystem](https://capacitorjs.com/docs/apis/filesystem) 文档。

修改网页后同步：

```powershell
npm run android:sync
```

本机可用脚本从前端构建、同步资产到编译调试 APK 一次完成：

```powershell
& 'scripts/build-android-debug.ps1'
```

脚本默认使用 `D:\Android\Sdk` 和 `D:\Android\jdk-21.0.12.1+1`，可用 `-SdkRoot`、`-JdkRoot` 指定其他路径。它先检查 Android 36 平台和 Build Tools 35.0.0，再运行 `npm run android:sync`、Gradle `:app:assembleDebug`；成功后输出 [`app-debug.apk`](../android/app/build/outputs/apk/debug/app-debug.apk)。Capacitor 当前生成的 `android/app/capacitor.build.gradle` 将 Java 源码级别设为 **21**；仅用 JDK 17 的第一次编译在 `:capacitor-android:compileDebugJavaWithJavac` 报“无效的源发行版：21”。因此该项目的构建脚本改用 JDK 21。
