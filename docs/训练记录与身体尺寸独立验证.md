# 卧推训练记录能否补充身体尺寸标定

更新：2026-09-25。使用 Jensen、Jensen 与 Pedersen 的 [28 人公开力量测试和人体测量数据](https://zenodo.org/records/3253731) 做一次**独立受试者留出**检查。数据按 CC BY 4.0 发布；本仓库只存复算脚本和汇总结果，不存参与者逐行数据。两份原始工作簿由脚本按 Zenodo 文件哈希取得并保存在被 Git 忽略的 `.cache/research/`。

## 问题与方法

用户希望填写身高、体重、围度及常用卧推重量和次数，借此得到个体化模型。这批资料包含 3–7 次最大卧推负重及次数、身高体重、胸宽、胸深、肩宽、腕围，却**没有**臂围、胸大肌体积、MRI 肌肉截面积、肌电或实际单肌肉力量。资料里的体脂率由 BMI 和登记性别的公式计算，不是独立测得的体脂，因此没有纳入本检查。

以 28 人中每次留出一人，训练数据只用其余 27 人。固定岭回归系数 10，标准化也只在训练折内计算。对比只填身高与体重，以及再加卧推测试重量与次数。另做一个加入登记性别和年龄的敏感性对照。误差是被留出者的绝对误差均值，单位厘米；`变化 = 加卧推后的误差 − 基线误差`，负数表示变好。区间为 20,000 次重抽取逐人误差差值的 95% 百分位范围，反映这组样本的不稳定性，并不是推广到所有健身用户的保证。

| 被预测尺寸 | 身高＋体重 MAE | 加卧推记录 MAE | 变化 | 变化的 95% 重抽样区间 |
| --- | ---: | ---: | ---: | ---: |
| 胸宽 | 2.215 | 2.047 | −0.168 | −0.482 至 +0.151 |
| 胸深 | 2.495 | 2.587 | +0.091 | −0.118 至 +0.296 |
| 双三角肌外侧宽度 | 2.367 | 2.389 | +0.022 | −0.272 至 +0.309 |
| 双肩峰宽度 | 2.001 | 1.989 | −0.013 | −0.145 至 +0.131 |
| 腕围 | 0.694 | 0.677 | −0.016 | −0.120 至 +0.094 |

加入登记性别和年龄后，胸宽误差从 2.164 降到 2.067 cm，其余四个尺寸的改变同样很小且区间都跨零。五个尺寸都没有显示足够稳定的增益，可以据此把用户卧推成绩转成胸部几何参数。

## 对产品的决定

- 训练重量与次数继续用于**卧推这个动作的能力粗估**和调用相应重量的示意动作；不驱动胸肌体积、红色发力图或单肌肉最大力量。
- 使用者直接量得的臂围、腰围、大腿围、小腿围优先用于外形示意。围度包含骨、脂肪、皮肤和多块肌肉，仍不能分解成单肌肉体积。
- 后续若要用训练记录建立肌肉量先验，需招募或取得带 MRI/超声局部肌肉体积、统一训练动作、近力竭程度和独立验证人群的数据；对实际发力还需要与姿势、外力和肌肉活动相关的独立测量。不能把本表尺寸预测误差当作肌肉力验证。

## 更接近力量标定的已有研究

[Simonsen 等 2024 年会议摘要](https://vbn.aau.dk/files/720824933/ESB2024_1.3_4_Simonsen.pdf)用 28 人的 11 项力量练习估算 1RM，在 AnyBody 模型里调整最大等长力量参数，再拿未作为该优化目标的测力仪最大自主收缩对照。摘要报告平均归一化误差从常规缩放的 20.4% 降至 12.8%。这支持**多项成绩可以用于校准肌群力量容量**的研究方向，比由卧推成绩反推胸围或胸大肌体积更接近本项目的目标。它是会议摘要，未提供可复算的个体原始成绩、参数和验证力矩；测试动作、软件模型和人群也不能直接移植到目前三个手机预设动作。我们下一步应在公开或新采集样本上复现“训练练习校准、独立测力动作验收”的流程，报告不同参数组的可辨识性和留人误差，再决定是否把任何力量参数接入个人发力图。

复算：在具备 `numpy` 和 `openpyxl` 的 Python 环境运行 `python scripts/benchmark_strength_anthropometrics.py`。脚本只下载两份约 22 KB 和 16 KB 的工作簿，校验 MD5，输出汇总 JSON；不下载视频包。
