# 卧推负重与侧向手力：当前证据和计算边界

更新：2026-09-25。App 的卧推参考动作是人工拟合的单侧胸廓—肩胛模型轨迹；本页记录负重输入目前能支持的计算，以及进入肌肉发力估算前的验证条件。

## 用公开逐次数据审查卧推动画速度

[Balsalobre-Fernández 等（2023）](https://doi.org/10.1519/JSC.0000000000004593)让 27 名受试者各以自报 1RM 的 50% 和 75% 做 5 次卧推，并用线性位移传感器与手机应用同时测量**向上推举阶段平均杠铃速度**。作者在 [Figshare 公开的 CC BY 4.0 CSV](https://figshare.com/articles/dataset/22615546) 含每种负重 135 条逐次配对记录；这里取线性位移传感器列，50%／75% 条件的逐次中位数为 0.80／0.55 m/s。135 条是同 27 人的重复动作，不能视为 135 个独立受试者。

当前单侧 OpenSim 人工参考路径的手部竖直位移为 0.284 m。默认 2.8 秒周期将下放和起举各分一半，所以在 175 cm 身高下的**示意**起举平均速度仅约 0.203 m/s。改变动作周期至 2.0 秒和 4.0 秒时，分别约为 0.284 和 0.142 m/s。这个量级低于上述两组实验逐次中位数，说明当前动画的时间尺度偏慢；但实验中的负重是按受试者自报 1RM 设定，App 当前 20 kg 默认值没有相应标定，所以不能把速度差直接解释成个体预测误差或肌肉力差。

复算：从 Figshare 下载 `data_VBTapp.csv` 到 `.cache/research/`，运行 `npm run benchmark:bench-velocity`。脚本检查四列、每组 135 次记录和 101 帧人工参考路径，从实际帧计算位移；结果保存于 [`src/data/bench_velocity_benchmark.json`](../src/data/bench_velocity_benchmark.json)。App 的卧推播放新增“慢速教学”及“实验 50%／75% 1RM 起举速度参照”。后两项把 175 cm 模型的起举时长分别换算为约 0.36／0.52 秒，**下放时长统一人为设为 1.0 秒**，所以完整周期约 1.36／1.52 秒；身高改变时，模型行程及起举时长同比变化，平均起举速度仍取对应实验中位数。时间轴阶段仍按 0–50% 下放、50–100% 起举显示。`npm run check:bench-tempo` 核查两档速度、身高缩放和跨阶段播放。

这些参照只是用实验的组层速度修正示意播放节奏，**没有**将真实实验关节轨迹、个人当前重量或肌肉激活拟合到模型。原 2.8 秒教学模式保留。该 CSV **没有逐帧运动捕捉、双手作用力、凳面与足底反力或肌电**，不能用来验证关节净力矩和单束肌肉发力。Blender 现有基础动作时间轴仍是对称 2.8 秒示意；这两档速度参照目前只在手机查看器播放。

[Kim 等（2025）](https://www.nature.com/articles/s41467-025-58624-6)还记录了卧推、肩推、深蹲等 11 种力量训练的同步 IMU 与光学运动捕捉，并在论文中给出部分示例和图表源数据；论文的数据可用性声明未提供可直接下载的完整逐帧实验记录。[Lee 与 Lee（2026）](https://doi.org/10.1038/s41597-026-07595-4)公布了含力板的深蹲等动作，但不包含卧推或实力举。这两项资料目前不能补齐本项目卧推的手部力和凳面接触输入。

## 起举轨迹与肌电的组层核对

[Larsen 等（2022）](https://pmc.ncbi.nlm.nih.gov/articles/PMC9658160/)测量 12 名有卧推经验男性的 1／3／6／10RM 最后一次卧推，使用同步杠铃编码器、三维动作捕捉和表面肌电。论文表 1 报告四档负重在起举第一个与第二个速度峰时，杠铃相对肩部的竖直高度和水平距离**组均值**。水平距离由约 0.160–0.176 m 降到 0.070–0.090 m。旧版人工 OpenSim 轨迹在起举时却让手沿卧推凳轴远离肩部，方向相反。

现在将人工最低姿态的手部位置调整为肩部向足端约 0.167 m；顶端约 0.078 m。`scripts/fit_tsm_bench_trajectory.py` 重新拟合七个关节角结点，`scripts/build_tsm_bench_lookup.py` 重新导出 101 帧；[组事件复算](../src/data/bench_group_path_benchmark.json)把论文八个组均事件按平均身高 183.8→175 cm 作统一比例缩放，再在本项目**同一条**起举路径上按竖直行程插值。水平距离平均绝对差为 **0.57 cm**、最大 **1.22 cm**。`npm run benchmark:bench-group-path` 可重新生成审查文件；其中 3 cm 门槛只是发现路径方向或量级回退的工程检查，**不是个人轨迹验收线**。

论文只有组均事件，没有公开个人逐帧数据；其数据声明为向作者合理申请。模型的“手部”与实验的杠铃标记不是同一个解剖点，肩原点定义也未逐人匹配，身高比例缩放只是近似。四档负重共用一条人工轨迹，并不能预测个人负重下的动作、支撑反力、肌肉力或肌电。该研究还报告，在接近力竭的最后一次动作里，四档负重的受测肌肉肌电**没有显著条件差异**；肱三头肌内侧头肌电从卡点前到卡点后上升。不能仅因输入重量较大，就给某块胸肌涂上更强的“发力红色”。

## 直接相关的实验研究

[Noteboom 等（2024）](https://pmc.ncbi.nlm.nih.gov/articles/PMC11224528/)对 10 名有经验的训练者记录了 21 种卧推技术变式，每种三次，使用 16 kg 杠铃。研究用动作捕捉记录身体运动，用器械中部应变传感器测量侧向手力；竖直手力则按每手 8 kg 的静态支撑力假设。其肌骨计算采用 Seth 等人的肩胛模型，并分析握距、肩外展角和肩胛位置对关节反力的影响。这使该论文成为本项目上肢模型的直接方法参照，但论文没有给出可直接下载的受试者逐帧原始数据链接；公开表格也不能替代逐帧验证集。

该论文报告手对杠铃的侧向施力有很大的个体差异，并在模型敏感性实验中观察到侧向力方向和大小可显著改变肩关节反力。因此，只用杠铃重力推断肩部“发力点”缺少关键输入。论文中的部分肌肉活动、关节反力属于作者模型的计算结果，不能直接当作本应用模型的验证真值。

已从 [Europe PMC 提供的论文正式补充材料](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC11224528/supplementaryFiles?includeInlineImage=false)核查 Supplementary Table S3；PDF 的 MD5 为 `a50a7647613d61e5e84eb4a35282feda`，与 Europe PMC 全文元数据一致。其 10 名受试者各自的平均水平手力为 `71.8, -49.0, 64.7, 20.1, 3.2, 90.9, 11.2, -15.2, 17.1, -34.4 N`，相对**假定**每手竖直力 78.48 N 的百分比为 `91.5, -62.4, 82.4, 25.6, 4.1, 115.8, 14.3, -19.4, 21.8, -43.8%`，正值代表手向杠铃外侧施力。跨人的这些平均比例最小 −62.4%、中位 +18.05%、最大 +115.8%。这是 16 kg 器械、这批训练者的汇总值，**不是**任意用户在其他重量下的真实范围或逐帧手力。数字已转录到 [`bench_lateral_force_study.json`](../src/data/bench_lateral_force_study.json)，只含论文统计量，不含受试者原始运动数据。

[Tanimoto 等（2023）](https://www.mdpi.com/2075-4663/11/8/154)提供另一个直接对照：14 名男性在 10RM 卧推中测量侧向杠铃力与胸大肌、肱三头肌肌电；81 cm 宽握的合并平均侧向／竖直比约为向外 30%，40 cm 窄握约为向内 10%。但两块肌肉的肌电活动比例在大多数比较中没有显著握距差异。该结果支持把**握距与侧向力视为独立的关键条件**，也提醒不能把外力矩情景的变化直接等同于胸肌／三头肌发力变化。论文只有群体结果，未提供可用于当前三维模型逐帧验证的受试者手力、运动学与凳面反力组合。

## 当前 App 的情景计算

在卧推“负重力学”页，取同一帧单侧参考轨迹中的手、肩和肘位置。输入总杠铃重量 `m` kg，假设双手均分竖直支撑力 `Fv = m × 9.80665 / 2` N。若右手**对杠铃**施加的侧向力为 `q × Fv`（向身体外侧为正），则杠铃**对手**的力在仰卧查看器坐标中为 `F = (−qFv, −Fv, 0)`。对肩或肘计算手与关节间的位置矢量 `r`，展示外力矩矢量的大小 `|r × F|`。参考几何只按输入身高相对 175 cm 等比例缩放。

页面现将补充表 S3 中跨人的 `q = −0.624、+0.1805、+1.158`（最小、中位、最大）代入所选重量和单侧人工轨迹。这样可直接观察有文献依据的比例差异对该**情景模型**的影响；它们不是用户的测量值、预测区间或动作建议。尤其把 16 kg 试验的手力比例套用到其他重量，尚无跨负重验证。先前固定的 `q = −0.10、0、+0.40` 仅是文献讨论所启发的三个假设，不再作为界面默认比较。

`npm run check:external-moments` 检查 3D 叉积、零侧向力时与垂直重力力臂公式一致、负重与身高缩放关系、补充表中力值与百分比的取整一致性，以及五个动作阶段的有限值。该校验不证明人工轨迹符合真实卧推。

## 尚未纳入的作用

- 手臂与躯干的质量及加速度，杠铃加速度、握持约束和双侧不对称。
- 凳面、足底接触与肩胛受压；个人肩宽、握距和肩胛位置对轨迹的校准。
- 关节净力矩、肩关节反力、肌肉稳定性约束、肌肉激活与单束肌肉力量。

因此，当前外力矩是**杠铃在一个假定手力方向下的力矩分量**，不是完整逆动力学结果。下一步需要获得有许可的逐帧卧推运动学和手力数据，对受试者几何、器械作用点与模型残余力矩做审查，然后才可比较肌肉求解结果与研究中的关节反力和肌电趋势。仅靠用户的身高、围度和训练记录不能唯一反推出逐帧侧向手力。

## Python RMR 求解器的单帧可行性探针

同一研究团队公开了 [Python RMR 求解器](https://github.com/ComputationalBiomechanicsLab/rmr-solver-py)，代码按 Apache 2.0 许可发布。已在本机检查提交 `651b4c742798afbeb90208fe6aa7e21d2c78909a`：它能初始化当前胸廓—肩胛模型的 17 个坐标、33 束肌肉和 50 个执行器。原版代码在 Python 3.13 开启肩关节稳定约束时，`paramsGH` 的 `@dataclass` 遇到可变数组类属性会报错；本机只在被忽略版本控制的研究副本里去掉了这个装饰器，随后运行 `scripts/probe_rmr_bench_static.py --gh-constraint`。App 没有包含或执行该求解器。

探针在人工卧推下放端点固定姿态，速度和加速度为零，仰卧重力指向原模型的 `−X`，手部受力经 OpenSim `PrescribedForce` 施于右手模型原点。三组输入为 0 kg、20 kg 仅竖直、20 kg 且手向外施力为竖直力的 40%。优化器三次均报告收敛；肩关节稳定夹角均贴近模型允许边界。**但没有卧推凳或足底接触**：地面到胸廓的 `ground_thorax_tx` 辅助执行器在 0 kg 时已提供约 240.7 N，20 kg 时约 338.5 N，相差约 98 N，恰是单侧额外杠铃重量。此辅助执行器在代替缺失的支撑条件，故算出的肌肉激活和关节反力绝不能用于 App 发力高亮。

逐项结果与求解器版本记录在[单帧求解探针 JSON](data/rmr_bench_static_probe.json)。下一步必须建立凳面、足底、双手器械连接及完整动作时序，再用独立实验数据检验支撑、残余执行器、肌肉激活和关节反力；收敛本身不构成验证。

## 显式凳面反力的受控探针

为了区分“缺少竖直支撑”和“支撑位置未知”两项问题，`scripts/probe_rmr_bench_static.py --gh-constraint --bench-support-sweep` 在同一人工静止姿态中，给胸廓施加沿模型竖直方向的预设反力。模型七个刚体总质量为 24.679 kg；反力大小直接设为 `模型质量 × 9.80665 + 总杠铃重量 × 9.80665 / 2`，所以 0 kg 为约 242.0 N，20 kg 为约 340.1 N。这是**先验指定的静力平衡量**，不是模型预测或实测凳面反力。作用点在胸廓局部坐标中固定后向 0.10 m，再把横向位置设为 −0.08、0、+0.08 m。

七组计算均报告优化收敛。加入这项反力后，胸廓竖直平移辅助执行器从原先 0/20 kg 时的约 241/339 N 降至约 1.1–1.8 N（绝对值）。但 **20 kg、无侧向手力时，仅把假设的凳面作用点横向移动 8 cm，胸廓三个旋转辅助力矩的合成量就在约 55.0–84.4 N·m 之间变化**。20 kg 且假设手向外施力为竖直力的 40% 时，模型仍需约 37.0 N 的胸廓侧向平移辅助力。肩关节稳定角在这些解中也贴近约束边界。可复核数值见[凳面支撑敏感性 JSON](data/rmr_bench_support_sweep.json)。

这说明按重量补齐竖直反力可以修复一项静力平衡缺口，却没有确定真实的凳面压力中心、足底与凳面的侧向反力或肌肉分担。[OpenSim 官方外力数据说明](https://opensimconfluence.atlassian.net/wiki/spaces/OpenSim/pages/53090636/Preparing%2BForce%2BData)强调外力的作用点和方向都需要与模型坐标一致；已有[卧推实验研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC7862765/)曾把力板置于凳下并测量杠铃水平力，说明这些输入需要专门测量。当前结果仍只作为求解器敏感性研究，不进入 App，也不能据此把某条肌肉标成“发力点”。
