## 下一步建模要求

1. 建立有明确可商用许可的双侧肩、胸、肘模型，至少包含胸大肌、三角肌前束和中束、肱三头肌、前锯肌及斜方肌的必要路径；记录每条路径的来源、附着点、包绕体和适用角度。
2. 卧推须表达肩水平内收及肩胛位置；实力举须表达肩上举、肘伸和肩胛上旋。不能把 Arm26 的单平面肩抬举直接当作卧推。
3. 与深蹲相同，先导出路径长度和力臂并做几何一致性检查，再把负重、惯量、关节力矩与肌肉优化求解接入。求解结果需经过外部实验对照才可作为“发力高亮”。

这份核查只说明可使用范围，不代表任何候选已完成动作或发力验证。

## Arm26 路径数据

`scripts/build_arm26_press_lookup.py` 以人工设定的肩抬举和肘屈伸角度扫掠 101 帧，导出 `docs/data/press_arm26_reference.json`。该文件**不再随 App 发布**：旧版 App 曾从同一文件绘制骨段、六条模型肌肉路径并显示长度与力臂，现版已不引用它，因此它与其余研究数据一起放在 `docs/data/`，由 `npm run check:bundle-assets` 守住“研究数据不进发布包”这条界线；`npm run check:arm26-lookup` 仍检查有限值、帧数、路径与数值一致性。折线显示与 OpenSim 模型路径长度的最大差异为 4.899 mm，主要来自包绕路径的曲线离散化。旧版 App 将整组参考几何按身高相对 175 cm 统一缩放，数值长度和力臂乘以同一系数；OpenSim 模型 1.10 倍均匀缩放探针显示抽查骨段、肌肉路径和力臂也约为 1.10 倍。此处理不使用臂围或体重，没有个体肌肉参数。该轨迹不代表实测实力举，数据中没有杠铃负重、肌肉激活或肌肉力。

缩放探针可用 `python scripts/probe_arm26_scaling.py` 复现，需先安装 OpenSim 4.6 Python 包。Arm26 数据保留为旧版研究对照；当前实力举参考页已经改用下述胸廓—肩胛模型。

## 胸廓—肩胛研究数据链

模型、几何与许可保存在 `assets/opensim/thoracoscapular/`，来源、修改关系和原论文见其中的 `NOTICE.md`。`scripts/build_tsm_press_lookup.py` 将锁骨抬高、肩胛上旋、肩抬举和肘屈伸做一个 101 帧的**人工角度扫掠**，每帧从新的 OpenSim 状态组装闭环肩胛机构，输出 `public/data/press_tsm_reference.json`。它包含 33 束肌肉的三维路径、肌腱路径长度和肩胛上旋/肩抬举/肘屈伸的模型力臂。路径折线与 OpenSim 计算长度最大相差 4.32 mm；相邻帧最大长度变化 4.10 mm；起点和终点返回同一姿态。`npm run check:tsm-lookup` 复核这些数值。此检查只验证数据提取与几何连续，不验证动作是否像真实实力举。

当前查看器把这条参考数据按身高统一缩放，用户臂展、臂围、体重和训练记录未进入模型。肩胛和肘关节虽在模型中，但轨迹不是用户动作或真实杠铃实力举的 IK 解；模型只有右侧，并缺少肱三头肌外侧/内侧头。不能将这一组长度或力臂用作发力高亮。

卧推参考页现使用同一单侧模型的独立仰卧几何研究。`scripts/fit_tsm_bench_trajectory.py` 将七个肩、肘关节角度节点拟合到人工设定的手部轨迹，结果保存于 `assets/opensim/thoracoscapular/bench_trajectory_knots.json`。`scripts/build_tsm_bench_lookup.py` 插值并导出 `public/data/bench_tsm_reference.json` 的 101 帧、33 束模型路径和四个关节坐标的力臂。端点手部下降约 28.4 cm，全程相对目标轨迹最大偏差约 10.0 mm；路径折线与 OpenSim 长度最大差异约 3.06 mm，相邻帧路径长度最大变化约 3.62 mm。`npm run check:tsm-bench-lookup` 可复核这些数值。这只证明人工轨迹可用该模型连续表示；没有实测卧推动作、双手杠铃、凳面支撑、负重动力学或肌肉发力验证。
