# 额外 25 lb 深蹲：手机预设支撑力与力板对照

更新：2026-09-25。来源为 [Scherpereel 等，*Scientific Data* 2023](https://www.nature.com/articles/s41597-023-02840-6) 的公开数据。论文说明采集了额外 25 lb（约 11.34 kg）的深蹲和力板数据，但没有交代重量的放置位置。这里检验的是**整个身体加重量的竖直地面支撑力**；与个人髋／膝力矩、单块肌肉力和真实杠铃背蹲仍有距离。

## 方法

`scripts/export_loaded_squat_template.mjs` 直接调用手机端 `squatVerticalSupportScenario`，给公开的 12 个受试者输入档案体重、统一假设身高 175 cm、额外重量 0 或 25 lb、2.8 秒周期、默认深度和零杠铃偏移。研究档案未提供每人身高；App 中重量路径的假设也没有对应的实验轨迹。

`scripts/benchmark_loaded_squat_template.py` 沿用此前的分段规则：两个近站立膝角谷点之间只留一个深蹲峰值，时长 0.9–4.0 秒，峰值屈膝至少 50°、动作幅度至少 40°，双侧活动标志覆盖至少一半。每次动作的内部 99 个阶段点，把实测左右力板竖直力之和除以 `(受试者体重 + 额外重量) × 9.80665`；手机示意力也用同一个总重量归一。逐次计算平均绝对误差（MAE），先取每人逐次中位，再取跨人中位，避免把相邻帧当独立受试者。

| 条件 | 人／完整动作 | 恒定总重量 MAE | 手机固定 2.8 秒轨迹 MAE | 固定轨迹优于恒定重量的人数 |
| --- | ---: | ---: | ---: | ---: |
| 自重 0 lb | 12／39 | 0.1143 | 0.1117 | 9／12 |
| 额外 25 lb | 12／36 | 0.1160 | 0.1085 | 10／12 |

误差单位均为各条件**身体加重量的静态总重力倍数**。25 lb 条件的逐人配对 MAE 改善中位数为 **0.0152**；以受试者为单位的探索性 bootstrap 95% 区间为 **0.0059–0.0255**。两条件下测得的平均力／静态总重量的逐人中位约为 1.0028／1.0010，说明总重归一大体合理。这不是手机对某个用户受力误差的置信范围。

为单独检查*让额外重量随示意轨迹加速*是否有用，还保留同一身体轨迹，但只给 25 lb 重量施加恒定重力。此对照的 25 lb 条件 MAE 是 **0.1091**；完整手机公式为 **0.1085**。逐人的配对改善中位只有 **0.0028** 倍总重量，9／12 人改善。因此总体收益大部分来自**身体运动的竖直加速度情景**及已知重量的静态重力；这批数据只给额外重量运动项提供很弱的支持，不能确定其真实放置和轨迹。

将筛选收紧为屈膝至少 70°、活动标志覆盖 60% 后，25 lb 保留 12 人 31 次；静态／手机固定轨迹 MAE 分别为 0.1162／0.1085，11／12 人改善，重量运动项仍是 9／12 人优于只计重量静态重力。这个敏感性结果仅检查分段门槛，不构成独立样本验证。

这里有一项对手机很有利的设置：用**实验膝角确定真实重复动作起止点**，再强行对齐手机预设周期。使用实验实测时长进一步缩放加速度时，25 lb 误差为 0.0985，但普通用户没有提供该实测时长和每次动作边界。两种条件可能有不同深度、节奏和停顿；权重放置未知；负重只有 25 lb 一档。这些数字都不能转成“个人关节负荷准确”或“肌肉越红越用力”。

## 复现

先按[动态深蹲验证数据](动态深蹲验证数据.md)取得公开 `0lbs`／`25lbs` 的 `angle`、`grf`、`activity_flag` CSV 与 `Subject_masses.csv`，然后在项目根目录运行：

```powershell
node scripts/export_loaded_squat_template.mjs
python scripts/benchmark_loaded_squat_template.py
python scripts/benchmark_loaded_squat_template.py --minimum-depth-deg 70 --minimum-active-fraction 0.6 --output .cache/lower-limb/loaded_squat_template_strict.json
node scripts/export-squat-evidence.mjs
```

逐人、逐次数字见 [loaded_squat_template_grf_benchmark.json](data/loaded_squat_template_grf_benchmark.json)。原始大文件与固定轨迹逐点预测仅在被 Git 忽略的 `.cache/`；手机离线包只含压缩摘要。
