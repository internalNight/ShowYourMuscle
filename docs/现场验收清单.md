# 现场验收清单（真机）

这一页只列**只能在真机上做**的验收。能在本机自动跑的部分已经有检查固定住了，不需要你在现场重复：

| 已经自动验收的部分 | 命令 |
| --- | --- |
| 界面在真实浏览器里启动、切换动作与视图、研究层加载 | `npm run check:ui-dom`（14 条行为） |
| 用户数据流：填参数、存记录、导出、导入、清空、390 px 不横滚 | `npm run check:ui-data-flows` |
| 断网可打开默认模型、三个动作与研究层；断网期间没有请求到达服务器 | `npm run check:ui-offline` |
| 离线包完整性（故意删一项必须被点名）与状态文案 | `npm run check:offline-cache` |
| 每个显示数字的容器的来源与置信状态 | `npm run check:output-provenance` |
| 包内权限、清单、网络调用面、存储键、外部链接 | `npm run check:shipped-package-audit` |

**仍然缺的就是这一页**：真机上的启动手感、动作查找速度、图例是否看得懂、以及 Android 的系统分享与文件选择。桌面无头浏览器的测量**不能**替代它们（见[网页启动与体积预算](网页启动与体积预算.md) 的局限一节）。

## 开始前

1. 装包：`D:\Android\Sdk\platform-tools\adb.exe install -r releases\muscle-atlas-debug-v130.apk`，或把 APK 传到手机点击安装（需允许“安装未知应用”）。
2. **记下构建标识**：打开应用，滑到页面最底部，footer 最后一行显示 `构建标识 muscle-atlas-v130`。反馈问题时请带上它——它同时对应包名、离线缓存名与包内审计记录。
3. 准备：一台 Android 手机；如果要做分享/导入，先准备一个能保存文件的位置。

## A. 安装与启动（约 5 分钟）

1. 先**强制停止**应用（设置 → 应用 → 肌动图谱 → 强行停止），再点图标打开。从点图标到**你能开始拖动三维人体**，记下大约几秒。
   - 参考：本机桌面无头浏览器冷启动首次绘制约 **0.31 秒**、模型就绪约 **0.29 秒**（`npm run measure:web-startup`）；真机会明显更慢，这里看的是**手感**：能不能"点开就能用"。
   - 观察：应先出现标题与"加载中"，模型出现后标签消失；不应白屏。
2. 状态徽标应显示 **`资源已内置`**。原生容器使用随包资产、**不注册 Service Worker**，所以它不会显示"资源缓存已完成"；若显示其它内容，记下原话。
3. 连续退出并重开 5 次：不应出现白屏、卡住或"加载失败"。

## B. 找到动作（约 2 分钟）

1. 从打开到**看清深蹲的某一块肌肉路径长度变化**，数一下点了几下（预期：动作标签默认就在深蹲 → 拖动时间轴即可）。
2. 切到"卧推"、"实力举"，各看一眼 OpenSim 参考视图是否加载出来（状态卡应写加载完成，不是"加载失败"）。
3. 在训练记录区：把筛选切到某个动作，展开全部记录，点其中一条的**"查看动作"**，确认它回到三维工作台并带上了那一组的重量。

## C. 图例与颜色（约 3 分钟，这一项的反馈最有价值）

1. **先不要看说明**，只看画面，说出下面每个颜色的意思：金色、橙色、紫色、红色。
2. 再读旁边的说明卡，对照自己刚才的判断。
3. 请把**猜错的那几条**记下来（例如"把金色当成发力大小"）。这正是目前无法自动验收的部分：颜色表达的是路径长度变化，不是发力。

## D. 断网（约 3 分钟）

1. 打开飞行模式（关 Wi-Fi 与移动数据）。
2. **完全关闭**应用再重开：默认模型、深蹲/卧推/实力举三个动作的参考视图、右腿研究形变层是否都能看。
3. 状态徽标是否仍显示 `资源已内置`；有没有出现加载失败或长时间转圈。
4. 恢复网络。

## E. 身体参数与训练记录（约 3 分钟）

1. 填身高、体重、胸围、腰围等，点"更新模型"，看模型是否变化。
2. 完全关闭再重开：参数是否保留。
3. 存一条杠铃记录（例如 80 kg × 5），确认列表里出现估算 1RM；再存一条哑铃记录，确认它注明"非杠铃器械不进入 1RM 粗估"。
4. 删掉刚存的两条记录。

## F. 系统分享与文件选择（约 3 分钟）

1. 点"导出备份"：应弹出**系统分享面板**，能保存到"文件"或发给自己。
2. 确认导出文件**只**含身体参数与训练记录（不含当前动作/重量等界面状态）；文件包含个人数据，注意保存位置。
3. 点"导入备份"：**系统文件选择**应能打开并选中刚才那份 JSON；导入后参数与记录应恢复。
4. 若面板没有弹出或选不到文件，记下出现的原话。

## G. 外接键盘（可选，约 2 分钟）

有蓝牙/USB 键盘时：先点一下三维区域让它获得焦点，然后 ←／→ 旋转、↑／↓ 俯仰、`=`／`+`／PageUp 拉近、`-`／PageDown 推远。缩放应在两端停住，旋转与缩放都只动相机、不改数据。

## 反馈问题时请附上

- **构建标识**（footer 最后一行，例如 `muscle-atlas-v130`）；
- 手机型号与 Android 版本；
- 哪一节、第几步；
- 屏幕上的**原话**或截图（"加载失败"的完整句子很有用）；
- 是否只在某个动作或某个视图出现；重开是否复现。

## 这一页**不是**什么

- 不是医学、生物力学或肌肉发力的验收：估算 1RM 是从你的记录按公式粗估，肌肉路径长度不是肌纤维应变，负重力学视图不是关节净力矩。
- 不覆盖 iOS：本仓库没有 macOS 构建环境，iOS 打包与验收仍未做。
- 不覆盖手感以外的量化：真机上的帧率、内存、耗电没有测量，也没有设备矩阵测试。
