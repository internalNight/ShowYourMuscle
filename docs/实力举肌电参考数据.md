# 实力举公开肌电数据：可验证内容与边界

更新：2026-09-25。

## 来源和实验条件

[Coratella 等（2022）](https://doi.org/10.3389/fphys.2022.825880)比较 8 名有竞赛经验的男性健美运动员进行杠铃前颈／颈后推举及器械前／后推举时的表面肌电。每种动作使用该动作的 80% 1RM，做 6 次；上推、下放各约 2 秒。杠铃试验**坐在带 80° 靠背的凳子上**。六处电极测量胸大肌锁骨部、肱三头肌外侧头、上斜方肌、三角肌前／中／后束。论文按个人最大自主等长激活归一化，提供每人每动作、每阶段的肌电均方根平均值。

作者的[原始汇总表](https://zenodo.org/records/5744051)在 Zenodo 公开，标注 CC BY 4.0。已核对下载文件 MD5 为 `e8b6c718179c993b0817208341e84130`，与论文给出的 accession 一致。`scripts/analyze_overhead_press_emg.py` 从该表的八位参加者行重新计算均值、样本标准差和配对差，并与表内均值行核对。源表只缓存在被 Git 忽略的 `.cache/research/`；可复算摘要见[JSON](data/overhead_press_emg_phase_summary.json)。

## 与模型有关的描述性结果

下表是 8 人的前颈杠铃推举均值，单位为相对个人最大等长激活的百分比。最后一列为上推阶段“前颈减颈后”的配对差，单位为百分点；这些不是肌肉力量或增肌效果。

| 肌肉电极 | 前颈上推 | 前颈下放 | 上推前颈减颈后 |
| --- | ---: | ---: | ---: |
| 胸大肌锁骨部 | 70.1 | 40.0 | +12.1 |
| 肱三头肌外侧头 | 89.7 | 65.0 | +1.5 |
| 上斜方肌 | 53.2 | 28.0 | +0.7 |
| 三角肌前束 | 86.1 | 45.1 | −5.6 |
| 三角肌中束 | 57.7 | 32.0 | −24.7 |
| 三角肌后束 | 28.6 | 23.6 | −46.8 |

胸大肌锁骨部的前颈上推肌电在 8 人中均高于颈后；三角肌中、后束均低于颈后。这与论文报告的方向一致。论文的推断统计使用重复测量模型及多重比较修正；这里的配对差只作可复算的描述，不重新宣称显著性。前颈推举六处肌电在上推均值都高于下放，但下放仍有活动；**肌肉路径变长不能据此被解释为不发力**。

## 对产品的用途

这份数据可以作为以后**同条件坐姿前颈推举**肌肉活动趋势的外部核查目标，也可以帮助定义 App 对“长度变化”和“肌肉活动”的不同图例。当前 App 的实力举是人工生成的**站姿**路径；这份数据没有逐帧标记点、关节角、手对杠铃的力、地面或座椅支撑反力，也没有每帧肌电。因此它不能校准现有轨迹、执行逆动力学、推断个人逐帧发力或支持红色发力高亮。表面肌电同样不直接等于单束肌肉力量。

下一步如要验证现有站姿动作，应取得授权可用的同步站姿运动学、杠铃与双手受力、足底反力及肌电数据；若使用这份数据做直接对照，应先在模型中另建与论文一致的坐姿和支撑条件。

## 站姿杠铃轨迹的组层筛查

[An 等（2025）](https://www.e-kjab.org/archive/detail/304)研究了 14 名有训练经验男性的站姿杠铃／器械推举，受试者平均身高 173.32 cm。其论文表 5 报告杠铃上推时相对右肩的垂直移动范围为 **44.33 ± 4.88 cm**，前后移动范围为 **9.28 ± 3.44 cm**；杠铃从身前向肩部后方移动的形状与当前教学预设相近。该论文也测量了八处肌电，但页面只提供组层表格，未发现可下载的逐人逐帧运动学、手力或足底反力。

依此把 `src/model.ts` 的站姿教学杠铃／手腕轨迹从原先约 49 cm 垂直、15 cm 前后，改为在平均身高 173.32 cm 输入时约 **43.87 cm 垂直、9.21 cm 前后**。随后按论文图文描述修正了原先从起点持续后移的路径：示意杠铃先略向前，再向后靠近肩部。相对肩部的起点、最前点、终点约为 11.88、13.86、4.65 cm。最前点发生在示意上推约 30% 进度；论文没有公开个人时序，**这个转折时点是教学设定，不是实验测量**。短臂展输入另受手臂长度上限约束。`npm run check:press-benchmark` 用论文组均值和标准差筛查竖直位移、前后位移、最前与最后距离；`npm run check:kinematics` 保证三个体型的臂段长度和固定握距。与手机端共用姿态的 153 帧 Blender 动作及个人化示例已重新导出，Blender 5.1.2 重新打开两份 `.blend` 后均通过十帧位置、路径和外形检查，其中增加了上推早期转折点附近的第 129 帧。

这只缩小了**示意杠铃路径的范围差**。论文没有披露足以复算的个体时序和外力；研究与本 App 的握距、个人体型及动作节奏也未逐项匹配。肩、肘和肩胛的真实轨迹以及肌肉力仍未通过实验验证。公开肌电原表来自前述坐姿研究，两项研究不能拼接成同一个人的完整动力学试次。

随后发现旧动画上推时左右手各向内滑动 7 cm，导致双手握距总计缩小 14 cm，与固定握持刚性杠铃的约束不符。v46 将实力举手腕横向位置固定在整次动作的同一杠铃点；`npm run check:kinematics` 现在逐帧检查卧推和实力举的双手间距及同步高度／前后位置。垂直和前后轨迹范围仍通过上面的论文组层筛查。两份 Blender 动作文件已再次导出并重新打开各核对九帧。这项修正让示意姿态满足器械的基本几何约束，不证明肘肩运动或力量正确。
