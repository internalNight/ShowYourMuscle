# 坐姿杠铃肩推的肌电参考

更新：2026-09-25。为寻找实力举的独立实验依据，核查 [Coratella 等（2022）](https://doi.org/10.3389/fphys.2022.825880) 的[公开表格](https://zenodo.org/records/5744051)。Zenodo API 给出 CC BY 4.0，文件 `Raw data_new.xlsx` 的 MD5 为 `e8b6c718179c993b0817208341e84130`，已下载到被忽略的 `.cache/overhead-press-emg/`。论文研究的是有约 80° 靠背的**坐姿**前方杠铃肩推，训练负重为各自实测 1RM 的 80%；当前 App 动作是**站姿**实力举。此资料只能提供相邻动作的肌电参考。

源表有六张肌肉工作表，每张第 2–9 行是 8 名参与者的八个条件／阶段均值；第 12–13 行是均值与样本标准差。六张表的 48 个均值及 48 个标准差与前八行逐列重算完全一致。这里没有逐帧原始肌电；数值是每块肌肉相对其自身最大等长肌电参考值的阶段平均 nRMS 百分数。不能把不同肌肉的百分数当作牛顿力比较。

| 肌肉 | 前方杠铃上推均值 | 下放均值 | 同一人上推高于下放 |
| --- | ---: | ---: | ---: |
| 胸大肌锁骨部 | 70.09% | 40.03% | 8/8 |
| 三角肌前束 | 86.09% | 45.11% | 8/8 |
| 三角肌中束 | 57.71% | 31.99% | 8/8 |
| 三角肌后束 | 28.62% | 23.58% | 6/8 |
| 肱三头肌外侧头 | 89.69% | 65.05% | 8/8 |
| 斜方肌上束 | 53.17% | 28.05% | 8/8 |

上表的人数来自各人配对差，不把 48 个条件均值视为独立受试者。原始表还允许比较杠铃前／后路径和器械肩推，但这些不同技术不等同于 App 预设的站姿杠铃路径。肌电电压不是肌肉力、力矩或肥大刺激的直接测量。本数据没有同步的杠铃运动、手力、地面反力、关节净力矩和肌肉实际力量，不能用于校准个人发力高亮。
