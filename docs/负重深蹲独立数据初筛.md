# 真实负重深蹲数据初筛

## 为什么检查这批数据

现有 12 人深蹲实验以自重和额外 25 lb 为主，尚不足以检验手机 App 在常用杠铃重量下的整体支撑力。López-Fernández 等人 2024 年的[论文](https://doi.org/10.1371/journal.pone.0307949)记录了 72 名受试者在 10%、30%、50%、70%、90% 估计 1RM 下各做四次背蹲，力板和腰部 IMU 均以 100 Hz 采集。[Zenodo 原始包](https://zenodo.org/records/12786141)以 CC BY 4.0 开放。它是一个**独立负重动作来源**，可用于检查力板资料是否足够支撑后续验证设计。

## 已完成的核查

下载的 `Data Motor Variability.rar` 为 45.3 MB，MD5 与仓库公布的 `ae111a413b0b3406ef118610b9b1bc5b` 一致。只把原始力板文本提取到 `.cache/barbell-intensity/extracted/Data Motor Variability/ForcePlatform`，未复制进手机包或仓库。`scripts/audit_loaded_squat_force_archive.py` 可复算，摘要见 [loaded_squat_force_archive_audit.json](data/loaded_squat_force_archive_audit.json)。

| 核查项 | 结果 |
| --- | ---: |
| 原始力板文本 | 380 份、76 个受试者编号，每人各有 5 档负重 |
| 通过保守量级筛查 | 365 份；其中 70 人五档都通过 |
| 被筛出的记录 | 15 份；部分第三列约为 ±9.8 或接近 0，无法与数百牛的记录直接混用 |
| 五档都通过的 70 人中，逐档中位第三列随负重增加 | 70 人 |
| 仅用 10% 与 90% 档中位值线性插值 30%／50%／70% 档 | 210 个中间档；绝对误差中位 37.2，观测值相对误差中位 3.18% |

程序暂把量级合理的第三列解释为竖直力、单位牛顿。第四列与前三列的欧氏范数逐样本符合，最大差约 `5×10⁻⁷`；原包没有明确字段字典，所以**列名与单位仍属推断**。通过规则是第三列中位数 >250、95 分位 >400；这个规则只用于发现明显量级异常，不等于论文作者的质量控制。Zenodo 页面明确说包内含一些因信号未正确记录而未用于论文的文件；因此原始编号 76 与论文分析 72 人不同并不意外，但无法从档案复原作者具体排除名单。

10%／90% 插值只验证这批记录在**同一人、同一力板**上的负重与信号量级关系。它用目标人的实测力板结果标定端点，不是手机预设动作、用户手填体重与训练记录的独立预测，也不提供每次动作峰值、关节力矩或单块肌肉力。

## 当前不能进入产品的结论

原始包没有个体体重、个体 1RM 数值、杠铃实际公斤数、关节运动学或逐次动作阶段标签；一些记录还存在测量异常。因而目前不能把用户的身高、体重、围度和常用重量代入，直接计算一个有独立实验误差保证的个人负重支撑力曲线，更不能据此把某块肌肉标为“实际发力”。若从同一条力板曲线反算体重或 1RM 再拿它评价预测，会把答案泄露给模型。

下一步应取得作者的字段／排除说明和匿名个体质量、1RM、逐次边界，或另找同时给出实际杠铃质量、人体运动学与完整力板的公开数据。届时先留出**整人**验证力板曲线，再考虑净关节力矩和肌肉分配的独立核查。
