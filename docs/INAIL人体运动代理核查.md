# 举箱时加入人体运动的外力探针

## 问题与资料

[已知箱重的外力基准](INAIL负重搬箱外力核查.md)只在静态总重上加入了**实验测得**的箱体加速度，尚未计入人体运动。本探针使用同一套 [INAIL Lifting Dataset 1](https://humandatacorpus.org/lifting-and-carrying-iso-11228/) 的人体三维标记点，检查一个粗略人体质心代理量能否解释剩余的脚下竖直反力。它仍是双手举箱，不能直接代表深蹲、卧推或实力举。

运行 `& '.cache/opensim-venv/Scripts/python.exe' scripts/probe_inail_body_motion.py`，从被前一个固定基准接受的 **10 人 84 次**试次生成[逐人和逐试次结果](data/inail_body_motion_probe.json)。代码用原始标记点和力板重算箱体候选，逐试次核对与固定基准的误差一致；没有重选有利试次，也没有用目标力板拟合系数。原始数据保存在 Git 忽略的 `.cache/`，不进入 App。

## 前向模型

在人体和箱子都只由双脚支撑的理想条件下，总竖直地面反力可写作 `(M+m)g + M·a人体 + m·a箱`。`M` 为资料受试者表中的体重，`m` 为随包协议中的箱重。本探针的 `a人体` **不是真实人体质心加速度**：骨盆高度取骶骨和左右髂前上棘标记点的平均；躯干高度取骨盆至双肩平均高度的 70%；左右大腿、胫段和足部用对应的髂前上棘、膝、踝、足跟与跖骨标记点插值得到。各段权重沿用项目此前从公开 `gait2354` 模型取得的固定质量比例，未测量这些人的真实体段质量。手臂和头部被并入躯干代理量。

人体代理高度和箱体高度都先以 6 Hz 四阶零相位低通处理，再以 101 点三阶 Savitzky–Golay 二阶导数求加速度。比较举起开始至结束时间段的逐试次 MAE，按 `(M+m)g` 归一；每人的试次中位数是跨人的汇总单位。为检查构造选择，代码还计算了只用骨盆加速度，以及躯干位置改取 50%、90% 的对照；这些对照都没有用力板拟合。

| 输入至竖直外力公式 | 跨人 MAE 中位／总重 | 优于仅箱体加速度的人数 |
|---|---:|---:|
| 静态总重 | 0.0507 | — |
| 静态总重＋实测箱体加速度 | 0.0383 | — |
| 再加实测骨盆加速度 | 0.0345 | 6/10 |
| 再加粗略人体质心代理，躯干 50% | 0.0337 | 9/10 |
| 再加粗略人体质心代理，躯干 70%（主方案） | **0.0332** | **9/10** |
| 再加粗略人体质心代理，躯干 90% | 0.0328 | 9/10 |

主方案相对只看箱子的逐人改善为 9/10，单侧符号检验 `p=0.01074`。这个探针是在前一个基准之后构造的；多个代理方案和这项检验都属探索性结果，不能把 p 值当作最终发力模型的确认性验证。90% 躯干位置的数字略低，也不代表已找到真实人体质心。

## 对产品的约束

新增人体运动项在这组实验里有帮助，说明只输入身体参数和器械重量无法完整描述动作过程。手机当前播放预设姿势，没有逐帧测量人体质心、真实箱体／杠铃加速度或外部接触。原实验的箱子可能仍受地面支撑的接触时刻也未建模。这里的 0.0332 **不是手机个人外力精度**；整体脚下反力也不能拆成关节净力矩或单块肌肉拉力。下一步要在匹配的杠铃动作中取得人体、器械和接触测量，完成跨人验证后，才能考虑将动力学需求用于个人发力高亮。
