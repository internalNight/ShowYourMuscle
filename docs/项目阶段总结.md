# 肌动图谱：阶段总结（2026-09-25）

## 目标与当前交付

项目目标是让用户在手机上填写少量身体参数和训练记录，查看与自身尺寸相近的人体骨骼、肌肉和卧推、深蹲、实力举动作，逐步给出有实验证据支持的用力分析。

目前交付的是可离线使用的**教学与研究原型**：Vite/Three.js 网页与 Capacitor Android 调试工程、Blender 5.1.2 场景、三种预设动作、静态解剖参考层、局部围度外形反馈、肌肉路径长度变化着色、杠铃外力矩情景、训练记录及本地 JSON 备份。研究卡片展示来自公开实验的力板、肌电和关节力矩对照。身体输入和训练记录尚不能可靠反推出单块肌肉量或力量；长度变化色、外形变化和实验人群曲线均不表示用户自己的发力点。

## 本轮完成

- 完成 Georgia Tech 12 人深蹲的足部标记／力板 CoP 整人留出基准，并将其固定模板直接迁移到 GroundLink 7 人独立实验室数据；[方法和结果](深蹲压力中心跨实验室验证.md)。独立实验中相位线在 6/7 人优于固定点，但 CoP 误差中位仍为 2.4526 cm。
- 将有来源和限制的压力中心结果加入深蹲实验对照卡，更新离线缓存版本；构建产物包含相应数据。
- 生成 Android 调试 APK。电脑没有连接 Android 真机，WebView 性能、文件分享／导入及断网恢复还没有实际设备验收。

## 已知边界

- 深蹲模板比较借用实验测得的动作边界；手机只靠用户手填参数无法知道真实姿态、每脚反力或 CoP。
- 现有肌肉力优化在深屈膝区有容量与收敛问题，与独立肌电的对应关系也不稳定；[模型记录](OpenSim研究记录.md)不支持发布个人肌肉发力红色高亮。
- 骨骼与肌肉网格配准仍有厘米级偏差；围度改变的是外形示意，不是测量到的个体肌肉体积。
- 研究原始数据保存在本地 `.cache/`，不上传。第三方模型与解剖资产的来源和许可见各 `NOTICE` 文件；MyoSim 权利未厘清的生成场景已排除在仓库与 App 外。

## 下一阶段目标（本期后暂停）

1. 在 Android 真机验证安装、离线启动、三维性能、本地 JSON 导入导出与系统分享。
2. 用同一批实测负重动作逐级验收实际动作相位、双脚反力、CoP 和关节净力矩，并量化跨人误差；优先寻找使用少量手填参数仍有效的方案。
3. 修正骨与肌肉的解剖配准、深屈膝模型容量和优化收敛，并用独立肌电或其他可接受的实验指标核查肌肉分担。只有通过此门槛才考虑个人发力着色。
